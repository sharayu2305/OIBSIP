# Car Price Prediction with Machine Learning

## Internship
Oasis Infobyte Data Science Internship (OIBSIP)

## Objective
Build a machine learning model to predict car prices from vehicle specifications.

## Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

## Workflow
1. Load and explore the dataset.
2. Clean and preprocess the data.
3. Visualize car price patterns.
4. Train a Linear Regression model.
5. Evaluate predictions using MAE, RMSE, and R².
6. Save the model and prediction results.

## Dataset
205 records and 26 columns.

## Files
- OIBSIP_Task3_Car_Price_Prediction.ipynb
- car_price_prediction_model.pkl
- car_price_prediction_results.csv

## Conclusion
This project demonstrates the basic machine learning workflow for predicting car prices.
