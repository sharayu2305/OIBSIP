# Unemployment Analysis with Python

## Internship

Oasis Infobyte Data Science Internship (OIBSIP)

## Objective

To analyze unemployment trends using Python and visualize changes in unemployment rates over time.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Project Workflow

1. Import the required Python libraries.
2. Load and explore the unemployment dataset.
3. Clean and preprocess the data.
4. Analyze unemployment trends and patterns.
5. Create visualizations to understand changes in unemployment rates.
6. Interpret the results and summarize the findings.

## Key Findings

* Tripura recorded the highest average unemployment rate in the analysis, approximately 28.35%.
* Meghalaya recorded the lowest average unemployment rate in the analysis, approximately 4.80%.

*These findings are based on the dataset analyzed in this project.*

## Files

* Jupyter Notebook containing the unemployment analysis.
* Dataset used for the analysis, if included in the repository.

## Conclusion

This project demonstrates how Python data analysis and visualization techniques can be used to explore unemployment trends and identify differences in unemployment rates across regions.
